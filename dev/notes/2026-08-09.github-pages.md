# GitHub Pages (Sphinx → `gh-pages`)

Release docs only. Dev / pre-release builds stay local (`poe docs html|watch`).

## Layout

Publish the Sphinx HTML tree **as the branch root**:

```text
gh-pages/
  .nojekyll          # required — Sphinx uses `_static/`, …
  index.html
  _static/
  content/
  apidocs/
  …
```

## Publish

**Local** (builds a `git archive` of the ref, never the dirty tree):

```bash
poe docs:publish --ref v0.5.3
# or: python dev/bin/publish-docs --ref v0.5.3
```

- Rejects non-final PEP 440 versions (`a` / `b` / `rc` / `dev` / local) unless
  `--force`.
- `--dry-run` builds + creates the orphan commit object without pushing.
- Push is plain `git` plumbing (orphan commit → `origin/gh-pages`). No
  `ghp-import`, no third-party deploy Actions.

**CI:** [`.github/workflows/docs.yml`](../../.github/workflows/docs.yml) on
`v*` tag pushes (and `workflow_dispatch` with a tag). Runs the same script
with `contents: write` so `GITHUB_TOKEN` can push `gh-pages`.
