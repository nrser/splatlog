splatlog.lib.text.number¶

Number formatting.

fmt_number() formats numbers by applying a str.format() template — the same format mini-language f-strings use — so callers can easily express precision, grouping, sign, alignment, percent, and even currency (e.g. f_fmt="${:,.2f}").

FmtOpts exposes one template per type; when a field is empty it falls back per the last column (“compose” builds the result from formatted components rather than a single template):

API¶

splatlog.lib.text.number._is_inf(x: float | Decimal) → bool¶

Is x (positive or negative) infinity?

Decimal is checked with its own is_infinite() because math.isinf() coerces to float first — which would misreport a finite-but-huge Decimal (one that overflows float) as infinite.

splatlog.lib.text.number._is_nan(x: float | Decimal) → bool¶

Is x NaN?

Decimal is checked with its own is_nan() because math.isnan() coerces to float, which raises on a signaling NaN.

splatlog.lib.text.number._sign(n: float) → str¶

"-" for negatives, otherwise "+" — joins complex components (e.g. the +/- in 1+2𝒊).

splatlog.lib.text.number.fmt_number(
x: Number,
opts: FmtOpts,
) → str¶

Format a number by applying a str.format() template.

Each type has its own template option — i_fmt (int), f_fmt (float), dec_fmt (decimal.Decimal), Q_fmt (Fraction), and C_fmt (complex). Since the templates are just the format mini-language, anything an f-string supports works. Empty ones fall back: Decimal to f_fmt, and Fraction/complex to composing from their formatted components.

Examples

  • Defaults — int is grouped with no decimal point; float and Decimal use grouped “general” format ("{:,g}"); Fraction and complex compose from their formatted components:

    >>> from decimal import Decimal
>>> from fractions import Fraction

>>> fmt_number(1_234_567)
'1,234,567'

>>> fmt_number(1_234.5678)
'1,234.57'

>>> fmt_number(Decimal("1000.5"))
'1,000.5'

>>> fmt_number(Fraction(1, 3))
'1/3'

>>> fmt_number(complex(1234, 5))
'1,234+5𝒊'

    The f_fmt default ("{:,g}") drops insignificant trailing zeros and switches to scientific notation for very large/small magnitudes:

    >>> fmt_number(1000.0)
'1,000'

>>> fmt_number(12_000_000.0)
'1.2e+07'

  • Precision & grouping — override f_fmt with any spec:

    >>> fmt_number(3.14159, f_fmt="{:.2f}")
'3.14'

>>> fmt_number(1234567, i_fmt="{:_}")
'1_234_567'

  • Currency, sign, percent, alignment — all expressible inline:

    >>> fmt_number(1234.5, f_fmt="${:,.2f}")
'$1,234.50'

>>> fmt_number(42, i_fmt="{:+}")
'+42'

>>> fmt_number(0.1234, f_fmt="{:.1%}")
'12.3%'

>>> fmt_number(12.5, f_fmt="{:>10,.2f}")
'     12.50'

  • Decimal targeting — dec_fmt formats Decimal without touching float (handy for a “poor-man’s currency”), falling back to f_fmt when empty:

    >>> fmt_number(Decimal("1234.5"), dec_fmt="${:,.2f}")
'$1,234.50'

>>> fmt_number(1234.5, dec_fmt="${:,.2f}")
'1,234.5'

  • Fractions & complex — composed from formatted components by default; give Q_fmt/C_fmt a template to format the value whole, or swap the imaginary unit via C_i:

    >>> fmt_number(Fraction(1, 3), Q_fmt="{:.3f}")
'0.333'

>>> fmt_number(complex(1, 2), C_i="j")
'1+2j'

  • Non-finite float/decimal.Decimal values use the n_inf and n_nan symbols:

    >>> fmt_number(float("inf"))
'∞'

>>> fmt_number(float("-inf"))
'-∞'

>>> fmt_number(float("nan"))
'NaN'

>>> fmt_number(Decimal("Infinity"))
'∞'

    Setting a symbol to "" falls back to f_fmt (i.e. however the format mini-language renders it):

    >>> fmt_number(float("inf"), n_inf="")
'inf'

>>> fmt_number(float("nan"), n_nan="")
'nan'
