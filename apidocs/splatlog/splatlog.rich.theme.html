splatlog.rich.theme.THEME¶

‘Theme(…)’

Base theme with splatlog-specific additions in the log (extended) and report (created) prefix namespaces.

The styles layer on top of the undocumented rich.default_styles.DEFAULT_STYLES (see source), which consists of:

Basic Styles

  • none: rich.style.Style.null, a specialized empty style (Style()-equivalent) that triggers fast paths.

  • reset: All attributes "default" or False.

  • Attribute manifestations:

    dim, bright, bold, strong, italic, emphasize, underline, blink, blink2, reverse, strike

    all of which should be pretty strait-forward, with the exception of reverse.

    From what I can tell, reverse is a relative transformation that inverts the current style — applying to white text on black background will produce black text on white background.

  • Colors: The ANSI colors

    black, red, green, yellow, magenta, cyan, white

    and only those colors, for whatever reason.

  • "code": Style(reverse=True, bold=True)

splatlog.rich.theme.to_theme(
value: ToTheme | None = None,
*,
base: Theme = THEME,
) → Theme¶

Convert a value into a rich.theme.Theme.

Parameters

  • value: Converted as follows:

    • rich.theme.Theme: returned as-is.

    • rich.syntax.SyntaxTheme: converted via a copy of the procedure from rich.traceback.Traceback.__rich_console__().

      Used in splatlog.rich.EnrichedException to convert the theme attribute from rich.traceback.Traceback.

    • Mapping: layered over the default THEME.

    • typing.IO: read theme from file via rich.theme.Theme.from_file().

    • None: returns a copy of the default theme.

Returns

A rich.theme.Theme instance.

Examples

Default returns a copy of the base theme:

>>> theme = to_theme()
>>> isinstance(theme, Theme)
True

Pass a Mapping to add/override styles:

>>> theme = to_theme({"custom.style": "bold red"})
>>> "custom.style" in theme.styles
True

Existing Theme is returned as-is:

>>> original = Theme({})
>>> to_theme(original) is original
True
splatlog.rich.theme.override_ansi_colors(
theme: Theme = THEME,
**name_color_map: str | Color,
) → Theme¶

Copy theme, overriding styles using ANSI colors named in name_color_map with their corresponding values.

Used to fix display of ANSI named colors in situations where it’s difficult to adjust the “terminal” color values (Jupyter notebooks in VSCode extension) but True Color (24-bit color) rendering is available.

Parameters

  • theme: theme to apply overrides to, defaults to the splatlog theme.

  • name_color_map: mapping of ANSI color names ("blue", "red", etc.) to replacement. The replacement is used as the color argument to rich.style.Style. Typically a hex string like "#439af4".

Example

from rich.console import Console

console = Console(
    theme=override_ansi_colors(blue="#509dea", bright_blue="#439af4")
)
