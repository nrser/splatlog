splatlog.json.reducers¶

Reducers for converting arbitrary Python objects to JSON-encodable forms.

This module provides JSONReducer — a dataclass that pairs a match predicate with a reduction function — along with a suite of pre-configured reducers for common Python types (classes, dataclasses, enums, exceptions, mappings, collections, etc.).

Reducers are ordered by priority, allowing the JSON encoder to try more specific reducers before falling back to generic ones.

API¶

class splatlog.json.reducers.JSONReducer¶

A reducer converts objects to splatlog.types.JSONEncodable that can then be JSON encoded by json.JSONEncoder.

splatlog.json.JSONEncoder uses a priority-ordered list of reducers to extend the capabilities of json.JSONEncoder to cover more of the things you may want to log.

Each reducer consists of:

  • JSONReducer.priority determining evaluation order (lower = earlier).

  • JSONReducer.name for identification and debugging.

  • JSONReducer.is_match predicate to test if this reducer handles an object.

  • JSONReducer.reduce function that transforms the object to a JSON-encodable form.

Reducers are immutable and comparable (ordered by priority, then name).

Parameters

Returns

A new JSONReducer with JSONReducer.is_match set to isinstance(obj, typ).

classmethod method(method_name: str, priority: int) → Self¶

Create a reducer that matches objects with a specific method.

The reducer matches any object that has a callable zero-argument method with the given name, and reduces by calling that method.

Parameters

  • method_name: Name of the method to look for and invoke.

  • priority: Evaluation order (lower = earlier).

Returns

A new JSONReducer that calls obj.<method_name>() on matched objects.

splatlog.json.reducers.reduce_exception(
error: BaseException,
) → dict[str, JSONEncodable]¶

Convert an exception to a JSON-encodable dictionary.

Produces a dict containing:

  • type: The exception class name (e.g. "ValueError").

  • msg: The string representation of the exception.

  • traceback: (if present) List of frame dicts from TRACEBACK_REDUCER.

  • cause: (if present) Recursively reduced __cause__ exception.

Parameters

  • error: The exception to reduce.

Returns

A dictionary representation of the exception suitable for JSON encoding.

splatlog.json.reducers.TO_JSON_ENCODABLE_REDUCER¶

‘method(…)’

Reducer for objects with a to_json_encodable() method (priority 10).

This is the highest-priority reducer, allowing objects to define their own JSON serialization by implementing a zero-argument to_json_encodable method.

splatlog.json.reducers.CLASS_REDUCER¶

‘JSONReducer(…)’

Reducer for class objects (priority 20).

Converts class objects to their formatted type name string.

splatlog.json.reducers.DATACLASS_REDUCER¶

‘JSONReducer(…)’

Reducer for dataclasses (priority 30).

Converts dataclass instances to dictionaries via dataclasses.asdict(), adding a __class__ key with the CLASS_REDUCER encoding of the dataclass type, so you know what it is.

Examples

>>> import dataclasses

>>> @dataclasses.dataclass
... class Point:
...     x: int
...     y: int

>>> pt = Point(x=1, y=2)

>>> DATACLASS_REDUCER.is_match(pt)
True

>>> DATACLASS_REDUCER.reduce(pt) == {
...     "__class__": "splatlog.json.reducers.Point",
...     "x": 1,
...     "y": 2
... }
True
splatlog.json.reducers.ENUM_REDUCER¶

‘instance(…)’

Reducer for enum.Enum members (priority 40).

Converts enum values to strings like "EnumClass.MEMBER_NAME".

Examples

>>> from enum import Enum
>>> from splatlog.json.reducers import ENUM_REDUCER

>>> class State(Enum):
...     STOPPED = 0
...     RUNNING = 1
...     CRASHED = 2

>>> state = State.RUNNING

>>> ENUM_REDUCER.is_match(state)
True

>>> ENUM_REDUCER.reduce(state)
'splatlog.json.reducers.State.RUNNING'
splatlog.json.reducers.TRACEBACK_REDUCER¶

‘instance(…)’

Reducer for types.TracebackType (priority 40).

Converts tracebacks to a list of frame dictionaries, each containing file, line, name, and text keys.

Examples

>>> def error_prone():
...     raise Exception("uh-oh")

>>> try:
...     error_prone()
... except Exception as err:
...     tb = TRACEBACK_REDUCER.reduce(err.__traceback__)

>>> tb == [
...     {
...         'file': '<doctest splatlog.json.reducers.__test__.TRACEBACK_REDUCER[1]>',
...         'line': 2,
...         'name': '<module>',
...         'text': 'error_prone()'
...     },
...     {
...         'file': '<doctest splatlog.json.reducers.__test__.TRACEBACK_REDUCER[0]>',
...         'line': 2,
...         'name': 'error_prone',
...         'text': 'raise Exception("uh-oh")'
...     }
... ]
True
splatlog.json.reducers.EXCEPTION_REDUCER¶

‘instance(…)’

Reducer for Exception (priority 40).

Converts exceptions to dictionaries with type, msg, and optionally traceback and cause keys. See reduce_exception for details.

splatlog.json.reducers.MAPPING_REDUCER¶

‘instance(…)’

Reducer for collections.abc.Mapping types (priority 50).

Converts mappings (dict subclasses, etc.) to a dict with __class__ and items keys, preserving the original class name.

splatlog.json.reducers.COLLECTION_REDUCER¶

‘instance(…)’

Reducer for collections.abc.Collection types (priority 60).

Converts collections (sets, frozensets, etc.) to a dict with __class__ and items keys. Lower priority than MAPPING_REDUCER since collections.abc.Mapping is also a collections.abc.Collection.

splatlog.json.reducers.FALLBACK_REDUCER¶

‘JSONReducer(…)’

Fallback reducer for any object (priority 100).

Matches everything and produces a dict with __class__ and __repr__ keys. This is the last resort when no other reducer matches.

splatlog.json.reducers.ALL_REDUCERS: tuple[JSONReducer, ...]¶

‘tuple(…)’

All reducers defined in this module, sorted by priority (ascending).

This tuple is constructed by collecting all JSONReducer instances from the module’s local namespace and sorting them.

Used as the default reducer set for splatlog.json.JSONEncoder.
