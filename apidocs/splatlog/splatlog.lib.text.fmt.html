splatlog.lib.text.fmt.fmt(
x: object,
opts: FmtOpts,
) → FmtResult¶

Format a value for concise, human-readable output.

Dispatches to specialized formatters based on the value’s type: typing constructs, types, and routines each have dedicated formatters.

Parameters

  • x: The value to format.

  • opts: Formatting options.

Returns

A formatted string representation.

Examples

  • Types & Type Hints — Formats type by qualified name, and typing hints with concise shorthands, clearly distinguished by enclosing angle brackets:

    >>> from typing import Optional, Callable, Literal
>>> from collections.abc import Collection

>>> fmt(str)
'<str>'

>>> fmt(Collection)
'<collections.abc.Collection>'

>>> fmt(str | None)
'<str?>'

>>> fmt(list[int])
'<int[]>'

>>> fmt(dict[str, int])
'<{str: int}>'

>>> fmt(Literal["A", "B", "C"])
"<'A' | 'B' | 'C'>"

>>> fmt(Callable[[int, int], str])
'<(int, int) -> str>'

    Additionally, the formatted runtime type can be added as a prefix when formatting a value by setting the FmtOpts.type option:

    >>> fmt(123, t=True)
'<int> 123'

>>> fmt({"x": 123, "y": 456}, t=True)
"<dict> {'x': 123, 'y': 456}"

    See fmt_type() and fmt_type_hint() for options and additional examples.

  • Functions & Methods — Uses inspect.isroutine() to detect functions and methods and format them clearly and concisely:

    >>> fmt(int.__add__)
'int.__add__()'

    Compare to what str (and repr()) will give you:

    >>> str(int.__add__)
"<slot wrapper '__add__' of 'int' objects>"

    See fmt_routine() for more info.

  • Numbers — Formats int, float, decimal.Decimal, fractions.Fraction, and complex via str.format() templates. By default int is grouped without a decimal point and float/decimal.Decimal use grouped “general” format:

    >>> fmt(1234567)
'1,234,567'

>>> fmt(1234.5678)
'1,234.57'

    The FmtOpts.i_fmt and FmtOpts.f_fmt options (plus FmtOpts.dec_fmt, FmtOpts.Q_fmt, and FmtOpts.C_fmt for Decimal/Fraction/complex) take any f-string spec, so grouping, precision, currency, and more are expressible inline:

    >>> fmt(1234567.5, f_fmt="${:,.2f}")
'$1,234,567.50'

    See fmt_number() for more.

  • Dates & Times — Formats datetime.datetime using the FmtOpts.dt_fmt option:

    >>> from datetime import datetime, date, time, timedelta

>>> fmt(datetime(2026, 3, 10, 14, 23, 45, 123_456))
'2026-03-10 14:23:45.123'

    Check out fmt_datetime() for details.

    Also handles datetime.date and datetime.time:

    >>> fmt(date(2026, 3, 10))
'2026-03-10'

>>> fmt(time(14, 23, 45, 123_456))
'14:23:45.123'

    See fmt_date() and fmt_time() for more.

    Produces a concise, readable rendering of datetime.timedelta as well:

    >>> fmt(timedelta(milliseconds=12))
'00:00:00.012'

>>> fmt(timedelta(days=1, hours=23, minutes=45, seconds=56))
'1d 23:45:56'

    fmt_timedelta() has more information and examples.

splatlog.lib.text.fmt.fmt_routine(
x: Routine,
opts: FmtOpts,
) → FmtResult¶

Format a function or method for display.

Lambdas are shown as λ(). Named functions include their qualified name followed by ().

Parameters

  • fn: The function to format.

  • opts: Formatting options.

Returns

A formatted string like module.func() or λ().

Examples

>>> import splatlog

>>> fmt_routine(splatlog.setup)
'splatlog.setup()'

>>> fmt_routine(splatlog.setup, fqn=False)
'setup()'

>>> fmt_routine(lambda x, y: x + y)
'λ()'

>>> def f():
...     def g():
...         pass
...     return g
>>> fmt_routine(f())
'splatlog.lib.text.fmt.f.<locals>.g()'
splatlog.lib.text.fmt.fmt_type(
x: type,
opts: FmtOpts,
) → FmtResult¶

Format a type for display.

Renders the type name with fmt_name(), surrounded by angle brackets (configurable) to distinguish it.

Parameters

  • x: The type to format.

  • opts: Formatting options.

Returns

The type’s qualified name, with or without module prefix per options.

Examples

>>> from collections.abc import Collection
>>> fmt_type(Collection)
'<collections.abc.Collection>'

>>> fmt_type(Collection, fqn=False)
'<Collection>'

>>> fmt_type(Collection, FmtOpts(fqn=False))
'<Collection>'

>>> fmt_type(Collection, FmtOpts(fqn=False), fqn=True)
'<collections.abc.Collection>'

splatlog.lib.text.fmt.fmt_type_hint(
x: object,
opts: FmtOpts,
) → FmtResult¶

Format a type hint for human-readable display.

Produces concise representations:

  • str? for str | None and Optional[str]

  • int[] for list[int]

  • {str: int} for dict[str, int]

Parameters

  • t: The type hint to format.

  • opts: Formatting options.

  • nested: Whether this is a nested type (used internally for parenthesization).

Returns

A formatted string representation of the type hint.

Examples

  • Optional types — unions of None with a single other type are abbreviated with a ? suffix:

    >>> fmt_type_hint(int | None)
'<int?>'

>>> fmt_type_hint(None | int)
'<int?>'

    This includes construction using typing.Optional:

    >>> from typing import Optional

>>> fmt_type_hint(Optional[int])
'<int?>'

    We used to exclude typing.Literal from this rule, but on revisit favored consistency and simplicity:

    >>> from typing import Literal

>>> fmt_type_hint(Literal["some"] | None)
"<'some'?>"

>>> fmt_type_hint(Optional[Literal[123]])
'<123?>'

    You can disable this feature by setting the t_opt_q option to False:

    >>> fmt_type_hint(int | None, t_opt_q=False)
'<int | None>'

>>> fmt_type_hint(Optional[Literal["some"]], t_opt_q=False)
"<'some' | None>"
splatlog.lib.text.fmt.fmt_range(rng: range, opts: FmtOpts) → str¶

Format a range for concise display.

Short ranges (≤3 elements) are shown in full. Longer ranges show the first elements and an ellipsis.

Parameters

  • rng: The range to format.

Returns

A string like [0, 1, 2] or [0, 1, ..., 100].
