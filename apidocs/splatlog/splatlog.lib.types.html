splatlog.lib.types¶

Library types: general, project-agnostic type hints and helpers.

Includes runtime type checking utilities wrapping the typeguard package.

type splatlog.lib.types.Number = int | float | Decimal | Fraction | complex¶

The numeric types splatlog treats as “numbers” for formatting and enrichment.

Note that bool — though an int subclass — is deliberately excluded by is_number(), so True/False fall through to their own handling rather than being rendered as 1/0.

splatlog.lib.types.is_number(x: object) → TypeIs[Number]¶

Test if x is a Number — an int, float, complex, Decimal, or Fraction.

bool is an int subclass but is excluded, so it can be handled as True/False rather than a number.

Examples

>>> from decimal import Decimal
>>> from fractions import Fraction

>>> [is_number(x) for x in (1, 1.5, 1j, Decimal("1"), Fraction(1, 2))]
[True, True, True, True, True]

>>> is_number(True)
False

>>> [is_number(x) for x in ("1", None, [1])]
[False, False, False]
splatlog.lib.types.is_typing(x: Any, *, include_type: bool = True) → bool¶

Test if a value is a type hint.

Warning

This function is best-effort — correctly identifying type hints is not strait-forward. Python’s type hint system is convoluted.

Parameters

  • x: The value to check.

Returns

True if x appears to be a typing.

Examples

Works for the usual typing constructs:

>>> import typing

>>> is_typing(typing.Any)
True

>>> is_typing(int | str)
True

>>> is_typing(typing.Literal["a", "b"])
True

>>> T = typing.TypeVar("T")
>>> is_typing(T)
True

>>> N = typing.NewType("N", int)
>>> is_typing(N)
True

>>> class P(typing.Protocol):
...     def f(x: int) -> str: ...

>>> is_typing(P)
True

Classes (type instances) are considered types, because they can be used as a type hint. This can be disabled with include_type=False.

>>> is_typing(int)
True

>>> is_typing(int, include_type=False)
False

Recognizes the subscripted abstract classes from collections.abc, as well as subscripted built-ins like list and dict:

>>> is_typing(list[str])
True

>>> from collections import abc

>>> is_typing(abc.Mapping[str, typing.Any])
True

The objects used to construct type hints should not themselves be considered typings:

>>> is_typing(typing.Optional)
False

splatlog.lib.types.assert_never(arg: Never, typ: Any) → Never¶

Statically assert that a line of code is unreachable.

If a type checker finds that a call to assert_never is reachable, it will emit an error. At runtime, raises AssertionError.

Parameters

  • arg: The value that should be unreachable (typing.Never).

  • typ: The expected type, included in the error message for clarity.

Examples

def int_or_str(arg: int | str) -> None:
    match arg:
        case int():
            print("It's an int")
        case str():
            print("It's a str")
        case _:
            assert_never(arg, int | str)
class splatlog.lib.types.IsType¶

Predicate that tests if object are instances of type T. Uses typing.TypeIs to mark passing values as instances of T.

Implemented as a immutable dataclass(), storing T in a t attribute and testing values with __call__().

Examples

Does what you would expect:

>>> is_int = IsType(int)
>>> is_int
IsType(t=<class 'int'>)

>>> is_int(123)
True
>>> is_int("hey")
False

IsType can be used with functions like splatlog.lib.collections.find() that parameterize over typing.TypeIs to discriminate return type.

The result of find(IsType[T], ...) can be safely assigned to a variable of type T, as seen here assigning find(IsType(int), ...) to an int:

>>> from splatlog.lib.collections import find

>>> values: list[object] = ["hey", 123, "ho"]
>>> i: int = find(IsType(int), values)
>>> i
123

splatlog.lib.types.satisfies(
value: Any,
expected_type: type[splatlog.lib.types.satisfies.T],
) → TypeIs[splatlog.lib.types.satisfies.T]¶

Check if a value satisfies a type at runtime.

Uses typeguard.check_type() to perform the check and returns a TypeIs for use in type narrowing.

Parameters

  • value: The value to check.

  • expected_type: The type to check against.

Returns

True if value is of expected_type, False otherwise.

Examples

>>> satisfies(123, int)
True

>>> satisfies("hello", int)
False

>>> satisfies([1, 2, 3], list[int])
True
splatlog.lib.types.check(
value: Any,
expected_type: type[splatlog.lib.types.check.T],
) → splatlog.lib.types.check.T¶

Check that a value satisfies a type at runtime, returning it if so.

Uses typeguard.check_type() to perform the check. Raises typeguard.TypeCheckError if the check fails.

Parameters

  • value: The value to check.

  • expected_type: The type to check against.

Returns

The value unchanged if it satisfies expected_type.

Raises

typeguard.TypeCheckError: If value does not satisfy expected_type.
