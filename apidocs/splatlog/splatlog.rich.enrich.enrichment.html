splatlog.rich.enrich.enrichment¶

Options for splatlog.rich.enrich.

EnrichOpts extends FmtOpts as the place for Rich-display concerns that don’t belong in the foundational splatlog.lib.text layer (which must not depend on Rich). Because it is-a FmtOpts, a single instance can be handed straight to any fmt_* formatter or segment tokenizer.

It currently adds no fields of its own — it’s kept as the extension point for forthcoming rendering-context options.

The @enrichment decorator mirrors @formatter: it merges the opts/kwds an enrichment function is called with into a single EnrichOpts so implementations only ever see one.

splatlog.rich.enrich.enrichment.set_default_enrich_opts(
opts: EnrichOpts | None = None,
/,
**kwds: Unpack[EnrichKwds],
) → None¶

Set the global enrich-level overrides layered over the fmt default.

These apply whenever splatlog.rich.enrich.enrich() (and the other @enrichment functions) are called without explicit options. Shared formatting fields not overridden here still come from the fmt default (see set_default_fmt_opts()).

Parameters

  • opts: Replace the overrides with this instance’s non-default fields. Pass a plain EnrichOpts() to clear them.

  • kwds: EnrichKwds merged over the (possibly replaced) overrides.

Examples

>>> from splatlog.rich.enrich import enrich

>>> set_default_enrich_opts(i_fmt="{:_}")
>>> enrich(1234567).plain
'1_234_567'

>>> set_default_enrich_opts(EnrichOpts())  # clear the overrides
>>> enrich(1234567).plain
'1,234,567'
splatlog.rich.enrich.enrichment.override_enrich_opts(
opts: EnrichOpts | None = None,
/,
**kwds: Unpack[EnrichKwds],
) → Iterator[EnrichOpts]¶

Temporarily override the default EnrichOpts within a with block.

The override layers over the current effective default and applies only to the current context (thread/async task), restored on exit.

Parameters

  • opts: Non-default fields to overlay. When None (default), only kwds are applied.

  • kwds: EnrichKwds overlaid on top.

Examples

>>> from splatlog.rich.enrich import enrich

>>> with override_enrich_opts(i_fmt="{:_}"):
...     enrich(1234567).plain
'1_234_567'

>>> enrich(1234567).plain
'1,234,567'

class splatlog.rich.enrich.enrichment.Enrichment¶

Bases: typing.Protocol

Type of @enrichment functions — the enrich-layer analog of Formatter.

Options can be provided as a unified EnrichOpts in the second (positional) argument, attribute-wise as EnrichKwds keyword arguments, or both (keywords taking precedence). The merging happens in @enrichment, so the wrapped EnrichImpl always receives a single EnrichOpts.

splatlog.rich.enrich.enrichment.enrichment(
fn: EnrichImpl[splatlog.rich.enrich.enrichment.enrichment.T, splatlog.rich.enrich.enrichment.enrichment.R],
) → Enrichment[splatlog.rich.enrich.enrichment.enrichment.T, splatlog.rich.enrich.enrichment.enrichment.R]¶

Decorator used to define an enrichment function.

Mirrors @formatter: the wrapped implementation always receives a single, resolved EnrichOpts, while callers may pass an EnrichOpts positionally, EnrichKwds keyword arguments, or both (keywords win). When neither is given, the current default (get_default_enrich_opts()) is used.
