splatlog¶

Root of the splatlog package, defining the general-use API. That is to say that import splatlog should give you everything you need for common use cases.

splatlog.setup(
*,
console: ToConsoleHandler | Literal[False] | None = None,
export: ToExportHandler | Literal[False] | None = None,
level: LevelSpec | None = None,
theme: splatlog.rich.ToTheme | None = None,
verbosity: ToVerbosity | None = None,
**custom_named_handlers: object,
) → None¶

Setup splatlog, enabling log output. Contemporary to logging.basicConfig() from the standard library.

Typically you’ll call this function once at the start of your program — in a main function or block, inside a start-up function or hook, or simply near the top of a script or notebook.

You can however call this function multiple times, and later configurations will seamlessly replace earlier ones. There are situations where this makes sense, such as setting up a default configuration immediately at program start then calling again when you’ve parsed options or loaded configuration.

Parameters

Note

All parameters default to None, which in all cases is ignored.

As such, calling setup() with no argument is a no-op.

  • console: create a logging.Handler writing to the console (terminal, command line) standard output (sys.stdout or sys.stderr streams).

    Focused on providing feedback during development. Defaults to using splatlog.rich.RichHandler for colored, tabular output.

    Accepts the following:

    1. None (default) is ignored; no action is taking regarding the console handler. This behavior is consistent across the export and custom_named_handler arguments as well.

    2. False removes the console handler, if any. This behavior is consistent across the export and custom_named_handler arguments as well.

    3. Any logging.Handler instance is added as-is, allowing users to substitute their own extension or alternative implementation.

    4. Everything else is used to construct a splatlog.rich.RichHandler. Full details in splatlog.named_handlers.to_console_handler(), but in brief:

      • True — all defaults, logs to sys.stderr.

      • collections.abc.Mapping — keyword arguments for the splatlog.rich.RichHandler constructor.

      • splatlog.types.Level — specify log level.

      • splatlog.types.StdioName, typing.IO, or rich.console.Console — where to write output.

    Examples

    Log logging.INFO and above to sys.stderr.

    
splatlog.setup(level="info", console="stderr") # or simply
splatlog.setup(level="info", console=True) # as STDERR is the default

  • level: Set root logging level. Accepts integer levels from logging, like logging.INFO and alias splatlog.INFO, as well as string representations such as "info" and "INFO".

    Defaults to None, which is ignored.

  • theme: Set the default rich.theme.Theme.

    The default theme is used anywhere a theme is not explicitly provided, such as constructing rich.console.Console in splatlog.rich.console.to_console().

    Accepts the same values as splatlog.rich.theme.to_theme(), which is used to construct a theme if needed.

    Defaults to None, which is ignored.

    Examples

    Log everything (logging.DEBUG and up) to the console with logger names in pure magenta.

    
splatlog.setup(level="debug", console=True, theme={
    "log.name": "#FF00FF",
})

  • verbosity: Optional integer input dictating how much logging should be output.

    Represents the common -v, -vv, -vvv flag pattern, where verbosity_levels dictates how verbosity maps to logging levels. Higher verbosity should mean more logging output.

    Defaults to None, which is ignored.

splatlog.report(
include: ReportInclude = 'all',
*,
console: ToRichConsole | None = None,
show_placeholder_loggers: bool = False,
show_null_handlers: bool = False,
) → None¶

Print a logging system report to the console.

Displays all loggers, handlers, and filters in a rich.tree.Tree structure.

Parameters

  • include: Which loggers to include — "all" (default) or "configured" (only loggers with handlers or a non-NOTSET level).

  • console: Where to print the report. Accepts anything splatlog.rich.to_console() understands (including a ConsoleKwds mapping carrying a theme). Defaults to sys.stderr with the splatlog theme.

  • show_placeholder_loggers: Whether to show logging.PlaceHolder entries.

  • show_null_handlers: Whether to show logging.NullHandler entries.

Examples

import splatlog

# Print full report
splatlog.report()

# Only configured loggers
splatlog.report(include="configured")
