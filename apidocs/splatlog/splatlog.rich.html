splatlog.rich¶

Public API¶

The public API of splatlog.rich, re-exported here (the canonical import location) and documented where each symbol is defined.

THEME

Base theme with splatlog-specific additions in the log (extended) and report (created) prefix namespaces.

PALETTE_ANSI_DARK

A palette of colors for dark background, as map of color name str to hex value str.

THEME_ANSI_DARK

to_theme

Convert a value into a rich.theme.Theme.

get_default_theme

Get the current default theme.

set_default_theme

Set the default theme.

override_ansi_colors

Copy theme, overriding styles using ANSI colors named in name_color_map with their corresponding values.

NtvTable

A rich.console.ConsoleRenderable that renders a rich.table.Table with (name, type, value) columns from a TableSource mapping str names to object values.

TableSource

A collection of name/value associations, as either:

enrich_type_of

Create a Rich renderable for the type of a value.

enrich_type

Create a Rich renderable for a type.

enrich

Convert a Python value to a Rich renderable.

highlighted

highlight() some text.

REPR_HIGHLIGHTER

Shared rich.highlighter.ReprHighlighter instance for repr() syntax highlighting.

repr_highlight

Get a syntax-highlighted repr of a value.

to_console

Convert a value into a rich.console.Console.

to_style

Convert a value to a rich.style.Style, resolving from the styles in the given rich.console.Console.

RichHandler

A logging.Handler extension that uses rich to print tabulated, colored log records to the console.

TimeConfig

Controls how timestamps are displayed in log output.

ToTimeConfig

Accepted input types for time configuration.

Heading

A Rich renderable that displays a styled heading with a horizontal rule.

Section

A Rich renderable that displays titled content with a heading.

to_renderable_type

Convert a value to a rich.console.RenderableType.

with_framing

Wrap __rich_console__ output with width constraint and padding.

frame

Constrain width and add padding to content.

capture_riches

Capture Rich output as a string.

Helpers for working with the rich terminal formatting package.

rich is what we use to produce colorful, tabular log messages in the terminal.

splatlog.rich.capture_riches(
*objects: Any,
console: ToRichConsole | None = None,
**print_kwds,
) → str¶

Capture Rich output as a string.

Prints the given objects using a Rich console and returns the captured output as a string.

Parameters

  • *objects: Objects to print.

  • console: rich.console.Console specification (see to_console()).

  • **print_kwds: Additional keyword arguments for rich.console.Console.print().

Returns

The captured console output as a string.

Examples

>>> print(capture_riches("Hello", "World"))
Hello World
[1]

because you probably mean to use it… feel free to add {"show": False} if you really want it configured but hidden.
