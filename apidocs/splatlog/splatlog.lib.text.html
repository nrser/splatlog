splatlog.lib.text¶

Public API¶

These symbols are re-exported here for convenience — splatlog.lib.text is the canonical import location — but are documented alongside their definitions in the submodules linked below.

formatter

Decorator used to define a text formatter function.

Formatter

Type of @formatter functions, defining __call__() over a value of parameterized type T and formatting options FmtOpts.

fmt_pretty_repr

Format a str representation of any object with rich.pretty.pretty_repr().

FmtOpts

Options controlling text formatting behavior.

FmtResult

Formatting result; either a single str or an Iterable of str, allowing str generators (yield functions).

FmtFallback

FmtKwds

Keyword arguments type for FmtOpts fields.

get_default_fmt_opts

Get the current default FmtOpts.

set_default_fmt_opts

Set the process-wide default FmtOpts.

override_fmt_opts

Temporarily override the default FmtOpts within a with block.

fmt

Format a value for concise, human-readable output.

fmt_name

Get the qualified name of an object, optionally with module prefix.

fmt_type

Format a type for display.

fmt_type_of

Format the type of a value.

fmt_type_value

Format the type of a value.

fmt_type_hint

Format a type hint for human-readable display.

fmt_routine

Format a function or method for display.

fmt_range

Format a range for concise display.

fmt_list

Format a list of items. By default this is comma-separated, like A, B, C.

fmt_number

Format a number by applying a str.format() template.

fmt_datetime

Format a datetime.datetime with sub-second directives.

fmt_date

Format a datetime.date.

fmt_time

Format a datetime.time with sub-second directives.

iter_strftime_segments

Tokenize a strftime() template fmt against value, yielding (text, component) pairs.

STRFTIME_COMPONENTS

Maps a strftime() directive letter to the “component” name used as a style suffix when enriching (see iter_strftime_segments()).

fmt_timedelta

Format a datetime.timedelta using the splatlog.lib.text.FmtOpts.td_fmt template, default: "[%dd] [%H:%M:%S[.%3f]]".

iter_timedelta_segments

Tokenize a timedelta template fmt against td, yielding (text, component) pairs (the counterpart to iter_strftime_segments(), resolving [...] groups and the sign).

Text utilities.

Warning

No cross-package import at top-level

This module is considered foundational due to its primary use in formatting error messages. To avoid circular imports it is prohibited from importing other splatlog modules at the top-level.

Imports of other splatlog modules should be avoided, and placed inside function or method bodies if they can’t be.
