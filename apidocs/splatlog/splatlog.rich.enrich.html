splatlog.rich.enrich.enrich(
value: object,
opts: EnrichOpts,
) → rich.console.RenderableType¶

Convert a Python value to a Rich renderable.

Leaf values (numbers, dates/times) are first formatted via splatlog.lib.text — honoring EnrichOpts (an FmtOpts) — and then styled for Rich display. Types, routines, paths, and exceptions get their own enriched renderings, and values that are already Rich renderables are returned as-is.

Parameters

  • value: The value to enrich.

  • opts: EnrichOpts controlling formatting and enrichment.

  • kwds: EnrichKwds keyword arguments, merged over opts (see EnrichOpts.replace()) — e.g. enrich(x, i_fmt="{:_}").

Returns

A Rich renderable.

Examples

Printable strings are returned as-is:

>>> enrich("hello world")
'hello world'

Numbers are formatted (grouped by default) and styled:

>>> enrich(1234567).plain
'1,234,567'

Formatting is customized through EnrichKwds/EnrichOpts:

>>> enrich(1234567, i_fmt="{:_}").plain
'1_234_567'

Classes get special enriched formatting (module path . class name):

>>> from rich.console import Console
>>> _print = Console(no_color=True, force_terminal=False).print

>>> _print(enrich(dict))
dict

>>> from collections.abc import Mapping

>>> _print(enrich(Mapping))
collections.abc.Mapping

Other values are wrapped in rich.pretty.Pretty, which can break over multiple lines when the console is narrow.

>>> import sys
>>> from rich.console import Console
>>> narrow = Console(file=sys.stdout, width=15, no_color=True, force_terminal=False)
>>> data = {"a": 1, "b": 2}

>>> narrow.print(enrich(data))
{
    'a': 1,
    'b': 2
}
splatlog.rich.enrich.highlighted(
text: rich.text.TextType,
highlighter: Highlighter = REPR_HIGHLIGHTER,
) → Text¶

highlight() some text.

Differs from __call__() in str → Text conversion: no "\n" appended. That’s it.

Parameters

  • text: to highlight.

  • highlighter: By default, uses a ReprHighlighter, but you can provide another.

Returns

Highlighted Text.

splatlog.rich.enrich.enrich_type(
typ: type[object],
opts: EnrichOpts,
) → rich.console.RenderableType¶

Create a Rich renderable for a type.

If the type has a __rich_type__ method, calls it. Otherwise wraps in EnrichedType.

Parameters

  • typ: The type to enrich.

  • opts: EnrichOpts; its fqn controls whether the module prefix is included.

  • kwds: EnrichKwds keyword arguments, merged over opts — e.g. enrich_type(t, fqn=False).

Returns

A Rich renderable representing the type.

splatlog.rich.enrich.enrich_type_of(
value: object,
opts: EnrichOpts,
) → rich.console.RenderableType¶

Create a Rich renderable for the type of a value.

Shorthand for enrich_type(type(value)), but Enriched wrappers are unwrap()ped first so the underlying value’s type is reported (e.g. an EnrichedId yields int, not EnrichedId).
